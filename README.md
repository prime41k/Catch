# 🛡️ Catch.py v8.0 [remi sex]

Самый умный перехватчик ошибок для Python в мире.  
Не просто показывает ошибку — он переводит её на русский, объясняет причину и дает готовое решение.

> ⚠️ ВАЖНО: Импортируй модуль ПЕРВЫМ в главном файле проекта.

---

## 🚀 Фичи sexy mode

1.  💡 Мгновенные фиксы: Под каждой ошибкой пишется, как её исправить (например: *"Используй dict.get() вместо прямого обращения"*).
2.  📚 Словарь на 100+ ошибок: Включая специфичные ошибки Telegram (FloodWait, PeerIdInvalid), БД, сети и криптографии.
3.  🧹 Умная очистка стека: Скрывает мусор из site-packages и lib/python, показывая только твой код.
4.  ⚡ Быстрый дедуп: Защита от спама одинаковыми ошибками без тормозов (быстрый хеш вместо md5).
5.  🌐 Полный охват: Перехватывает ошибки в потоках, процессах (multiprocessing), futures и asyncio.
6.  🔇 Шумоподавление: Игнорирует системный шум (BrokenPipe, FloodWait), записывая его только в лог.

## ⚡ Использование

### Базовый перехват
import catch  # ПЕРВЫЙ ИМПОРТ!

@catch.catch_errors
def my_func():
    return 1 / 0

my_func()
Вывод:
⚠ ОШИБКА: Деление на ноль
💡 Как исправить: Проверь делитель перед операцией или используй try/except.
📍 Твой код:
  [1] main.py:5 в my_func()
      → return 1 / 0
### Асинхронность
@catch.async_catch
async def fetch_data():
    raise ConnectionError("Server down")

# Безопасный запуск с созданием loop
catch.run_safe(fetch_data())

# Или внутри уже запущенного loop
await catch.safe_run(fetch_data())
### Управление
catch.disable()  # Временно выключить перехват
catch.enable()   # Включить обратно

## 🛠 Настройки

Открой catch.py и измени константы в начале:

| Константа | Описание | По умолчанию |
|-----------|----------|--------------|
| LOG_FILE | Куда писать логи | "errors.log" |
| MAX_LOCAL_VARS | Сколько переменных показывать | 5 |
| MAX_STACK_FRAMES | Глубина стека твоего кода | 5 |
| SILENT_MODE | Скрыть приветствие при запуске | False |
