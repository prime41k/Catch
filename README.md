# 🛡️ Catch.py v6.3

**Ультимативный перехватчик ошибок для Python.**  
Перехватывает всё: от синтаксических опечаток до падения процессов и зависших асинхронных задач. Переводит ошибки на русский, показывает контекст, логирует в файл и не дает приложению упасть молча.

> **Внимание:** Модуль должен быть импортирован **ПЕРВЫМ** в вашем проекте, чтобы перехватить инициализацию интерпретатора.

---

## 🚀 Почему это круто

1.  **Полный охват:** Main thread, Threads, Multiprocessing (Process & Pool), Concurrent Futures, Asyncio, Warnings.
2.  **Русский язык:** 25+ частых ошибок переведены с пояснениями (`ZeroDivisionError` → `Деление на ноль`).
3.  **Контекст:** Показывает код строки, локальные переменные, стек вызовов.
4.  **Безопасность:** Защита от двойного логирования через `deque`.
5.  **Производительность:** Использует кэшированный traceback, не читает диск при каждой ошибке.
6.  **Гибкость:** Включение/выключение на лету (`enable()` / `disable()`).

```python
import catch  # ВСЕГДА ПЕРВЫЙ ИМПОРТ!

@catch.catch_errors
def my_function():
    return 1 / 0

my_function()

    ...
```

## 🛠 API Reference

### Декораторы

#### `@catch.catch_errors`
Перехватывает ошибки в синхронных функциях.
```python
@catch.catch_errors
def sync_func():
    raise ValueError("Test")
```

#### `@catch.async_catch`
Перехватывает ошибки в асинхронных функциях. Игнорирует `CancelledError`.
```python
@catch.async_catch
async def async_func():
    raise KeyError("Test")
```

### Функции запуска

#### `catch.safe_run(coro, return_exceptions=False)`
Async-обертка для безопасного выполнения корутины. Должна вызываться внутри event loop или через `asyncio.run()`.
```python
await catch.safe_run(my_coro())
# Или:
asyncio.run(catch.safe_run(my_coro()))
```

#### `catch.run_safe(coro, return_exceptions=False)`
Синхронная функция, которая сама управляет event loop. Если loop уже запущен — использует его, если нет — создает новый.
```python
catch.run_safe(my_coro())
```

### Управление

#### `catch.enable()`
Включает перехватчик (включен по умолчанию).

#### `catch.disable()`
Отключает перехватчик. Ошибки будут выводиться стандартным способом Python.

#### `catch.is_enabled()`
Возвращает `True`, если перехватчик активен.

## ⚙️ Конфигурация

Открой `catch.py` и измени константы в начале файла:

| Константа | Описание | По умолчанию |
|-----------|----------|--------------|
| `LOG_FILE` | Имя файла логов | `"errors.log"` |
| `MAX_LOCAL_VARS` | Макс. кол-во локальных переменных в выводе | `5` |
| `MAX_STACK_FRAMES` | Глубина стека вызовов | `3` |
| `INCLUDE_GLOBALS` | Показывать глобальные переменные | `False` |
