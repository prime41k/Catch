🦾 Catch.py — ловит ошибки, пока ты пьёшь чай

> Однажды я полдня искал баг, а это был просто `None`. Больше такого не повторится.

Catch.py — это модуль, который не просто показывает ошибку, а объясняет её по-человечески (на русском!) и даёт готовый фикс. Работает везде: в потоках, процессах, асинхронности и даже в Telegram-ботах.

---

🚀 Фичи

-Умный перехват — ловит ошибки в `asyncio`, `threading`, `multiprocessing`, `concurrent.futures`
- Готовые фиксы — подсказывает, как исправить (не просто "что-то сломалось")
-  Чистый стек — скрывает мусор из `site-packages`, показывает только твой код
-  Шумоподавление — не орёт на `BrokenPipe` и `FloodWait`, пишет их в лог
-  Один файл — просто скопируй `catch.py` в проект, никаких `pip install`

---

##Установка

```bash
# скачай файл
```

---

 Использование

Базовый перехват

```python
import catch  # ПЕРВЫЙ!

@catch.catch_errors
def my_func():
    return 1 / 0

my_func()
```

Вывод:

```
⚠ ОШИБКА: Деление на ноль
 Как исправить: Проверь делитель перед операцией.
 Твой код:
  [1] main.py:5 в my_func() → return 1 / 0
```

Асинхронность

```python
@catch.async_catch
async def fetch_data():
    raise ConnectionError("Сервер умер")

await catch.safe_run(fetch_data())
```

Управление

```python
catch.disable()   # отключить перехват (на время)
catch.enable()    # включить обратно
```

 Настройки

Открой catch.py и правь константы в начале:

Константа Что делает По умолчанию

MAX_LOCAL_VARS Сколько переменных показывать 5
MAX_STACK_FRAMES Глубина стека твоего кода 5
SILENT_MODE Убрать приветствие False
